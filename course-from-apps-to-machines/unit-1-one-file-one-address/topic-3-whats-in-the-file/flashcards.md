**Front:** `-` versus `d` at the start of an `ls -la` line

**Back:** `-` is a regular file. `d` is a directory.

---

**Front:** The `12` on `-rw-r--r--.   1 colin ubuntu   12 Jul 29 04:25 index.html`

**Back:** The file's size, in bytes.

---

**Front:** What does `ls -a` add to a listing?

**Back:** Names that start with `.`, which `ls` otherwise skips.

---

**Front:** What does the `.html` extension actually do?

**Back:** It is a hint about which app should open the file. It does not change the bytes.

---

**Front:** Same `index.html`, text editor versus browser

**Back:** The editor shows the characters. The browser draws the page.
