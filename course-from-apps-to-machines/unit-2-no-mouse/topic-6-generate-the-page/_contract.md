# Generate the page

**Unit:** 2 — No mouse
**Objectives (unit-numbered):**
7. Send output to a new file with `>` and append with `>>`.   [obj 7]
8. Chain commands with `|`.   [obj 8]
9. Build `index.html` from `echo` and `>>` so the file is generated, not typed.   [obj 9]

## Topic generation prompt

They can rebuild the folder. Now stop typing the page. Teach `>` (wipe and write) vs `>>` (append), then `|` as "the next program reads what this one printed". Generate `index.html` with two or three `echo` lines — they will do the full generated page in the project. One box: `nano` to edit in place (`Ctrl-O`, `Ctrl-X`); if they land in `vim`, `Esc` then `:q!`. Run `which nano` first (ungrounded whether macOS still ships it). A one-line `cat index.html` to see what they made. Do not teach `grep -rn` as a topic — one example is fine if a pipe needs a second stage. Do not recap `mkdir`.

## Grounded facts

- `wc -l` output shape: `7 /etc/hosts` [src 27]
- `grep -rn` output shape is `path:line:text`; one file omits `path:` [src 25, 26]
- `nano` ships by default on Ubuntu and Fedora [src 34]
- Whether `nano` ships on current macOS is ungrounded — teach `which nano` [Ungrounded]
- Being trapped in vim [src 160]
- `command not found` is read as "not installed" [src 159]
- Teach from: generating *this* `index.html`. Example commands:
  `echo '<h1>Ground Zero</h1>' > ~/projects/first-site/index.html`
  `echo '<p>Generated.</p>' >> ~/projects/first-site/index.html`
  Do not invent `wc` counts for the generated file.

## Requested activities

- READ: 700–1000 words. `>` vs `>>` on this file. One pipe (`ls ~/projects | wc -l` is fine — do not invent the number; tell them to read theirs). Then generate the two-line page. `flow` widget of `echo |` or of `>` vs `>>` is earned. nano/vim box. Ends with a generated `index.html`; next they look at the machine itself.
- FLASHCARDS: `>` vs `>>`; `|`; stdout; how to leave vim; `which nano`. 8 cards.
- QUIZ: 5 questions on wipe vs append, what a pipe hands off, and generating vs typing.

## Handoff

**Inherits:** they can rebuild the path; `index.html` still exists from Unit 1
**Leaves:** `index.html` has been regenerated with `>` / `>>` (generated bytes, not mouse-typed)
**Do not cover:** IP addresses, ports, HTTP, `python3`, editors beyond the box
