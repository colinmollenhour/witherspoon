**Front:** Which command prints where the shell is standing?

**Back:** `pwd` — print working directory. One absolute path. It changes nothing.

---

**Front:** What does `ls` list if you give it no path?

**Back:** The current directory — the folder the shell is standing in.

---

**Front:** What does `cd` change?

**Back:** The shell's current folder. It is a builtin. It does not move files.

---

**Front:** What is `..` when you pass it to `cd`?

**Back:** The parent folder. `cd ..` stands one level up.

---

**Front:** What does `cd -` do?

**Back:** Toggle to the previous folder and print the path you land in.
